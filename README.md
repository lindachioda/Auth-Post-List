# 🔐 Angular Post List – Authentication

Starting from the starter project:

1. Create a fake server for authentication, posts, and users.
2. Modify the user retrieval logic.
3. Create **Login** and **Registration** pages.
4. Send the authentication token with every request.
5. Protect the `users` route.
6. When the user is authenticated, display their name in real time in the navbar (`Hello <name>`) and hide the authentication routes.
7. Persist the authenticated user after a page refresh and automatically log the user out when the token expires.
8. Convert the routes to **lazy-loaded modules**.
9. Group common components shared between modules into a **Shared Module**.
